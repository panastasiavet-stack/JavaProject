**О проекте**

OTP Security Service — это учебное веб-приложение на чистой Java, предназначенное для усиления безопасности операций через одноразовые временные коды (OTP). Платформа позволяет создавать, доставлять и верифицировать коды подтверждения через несколько каналов коммуникации, не используя при этом сторонние фреймворки.

*Основной функционал*

— Аутентификация пользователей с JWT токенами
— Гибкая генерация OTP с настройкой длины и срока действия
— Многоканальная доставка кодов:
• Email (прямая отправка или имитация)
• Telegram (интеграция с ботом или симуляция)
• SMS (эмулятор протокола SMPP)
• Файловое сохранение
— Проверка кодов со статусами (ACTIVE/EXPIRED/USED)
— Автоматическое удаление устаревших кодов
— Разделение прав доступа (ADMIN / USER)
— Управление системой через административную панель

*Необходимое окружение*

Java 11+, PostgreSQL 17, Gradle, Telegram-аккаунт, SMTP-доступ

*Запуск*

Запустите Docker: docker compose up -d
Создайте БД: CREATE DATABASE otp_service;
Соберите и запустите: ./gradlew clean build && ./gradlew run
Приложение доступно по адресу http://localhost:8080

*API-методы*

— POST /api/auth/register — создание аккаунта
— POST /api/auth/login — вход в систему
— PUT /api/admin/config — настройка параметров OTP (только ADMIN)
— GET /api/admin/users — просмотр пользователей (только ADMIN)
— DELETE /api/admin/users/{id} — удаление пользователя (только ADMIN)
— POST /api/user/generate — создание кода
— POST /api/user/validate — проверка кода
